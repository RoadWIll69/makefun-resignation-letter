# The Funniest One-Line Resignation Letter

Entry for make.fun's "The Funniest One-Line Resignation Letter" bounty
(https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

The program writes one line to `entry.txt`: the resignation letter of a
retry loop that has delivered its two weeks' notice 4,096 times, because
no one reads the first 4,095.

Run it with:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node stdlib only) writes the line and verifies it is 1-140
characters and not only whitespace.
